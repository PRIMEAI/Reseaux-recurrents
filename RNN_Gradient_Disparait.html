Le gradient qui disparaît (ou qui explose)

Moulay Akhloufi

Pour remonter de hT jusqu’à h0, le gradient est multiplié T fois par la même matrice : ∂hT/∂h0 = ∏t diag(1 − ht²) · Whh. Si la plus grande valeur singulière de Whh est inférieure à 1, ce produit tend vers 0 ; si elle est supérieure à 1, il peut exploser. Simulation réelle avec n = 32 unités.

À retenir

σmax(Whh) < 1 : gradient qui disparaît → les premières étapes ne reçoivent presque aucun signal ; le RNN n’apprend pas les dépendances longues. Remède : changer d’architecture (LSTM, GRU).
σmax(Whh) > 1 : gradient qui explose (surtout sans tanh, ou quand les unités ne saturent pas). Remède : l’écrêtage du gradient (voir la page suivante).
La tanh aggrave la disparition : sa dérivée 1 − h² est ≤ 1 et devient très petite quand les unités saturent (|h| proche de 1). Bengio et al. 1994 ; Pascanu et al., ICML 2013.
